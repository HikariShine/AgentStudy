## NotebookLM 是什么？

NotebookLM 是 Google 推出的 AI 研究笔记工具。上传资料（文档、笔记、网页链接），AI 帮你整理、总结、问答，还能**生成讲解视频**。

生成的视频叫 "Audio Overview"，两个 AI "主持人" 对话讲解你的材料，配背景音乐，像一档播客节目。

**为什么选它？**

| 优势 | 说明 |
|------|------|
| 免费 | 目前完全免费，无额度限制 |
| 质量高 | 语音自然流畅，不像机器人 |
| 零门槛 | 不用写脚本、不用剪辑 |
| 多语言 | 支持中文、英文等 |

## 第一步：安装依赖

这几个工具都是一键安装。

### 1.1 安装 uv（Python 包管理器）

前几课装过可以跳过。

```bash
# macOS
brew install uv

# Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```

验证：
```bash
uv --version
```

### 1.2 安装 notebooklm-py

NotebookLM 的 Python 客户端，命令行操作用它：

```bash
uv tool install "notebooklm-py[browser]"
```

带 `[browser]` 是安装浏览器支持，登录需要。

验证：
```bash
notebooklm --version
```

### 1.3 安装 Playwright（浏览器自动化）

Playwright 控制浏览器，notebooklm-py 靠它模拟登录：

```bash
uv tool install playwright
playwright install chrome
```

`playwright install chrome` 会下载独立 Chromium 浏览器，约 100MB，耐心等待。

## 第二步：登录 NotebookLM

### 2.1 执行登录命令

```bash
notebooklm login
```

运行后自动打开浏览器，显示 Google 登录页面。

![NotebookLM登录页面](/home/shine/projects/AgentStudy/docs/config/10/notebooklm_login.png)

### 2.2 完成 Google 授权

1. 选 Google 账号（建议用小号，不确定 Google 是否会封号）
2. 允许 NotebookLM 访问权限
3. 看到 "授权成功" 后关闭浏览器

回终端能看到类似提示：

```
✓ Successfully logged in as: your-email@gmail.com
```

## 第三步：安装 Skill

### 3.1 下载 Skill 文件

手动安装。从仓库下载：

```bash
git clone https://github.com/HikariShine/AgentStudy.git
cp -r AgentStudy/skills/tiangong-notebooklm-cli ~/.openclaw/skills/
```

或下载压缩包解压到 `~/.openclaw/skills/tiangong-notebooklm-cli/`。

### 3.2 确认目录结构

```
~/.openclaw/skills/
└── tiangong-notebooklm-cli/
    ├── SKILL.md
    ├── skill.json
    └── scripts/
        └── notebooklm.mjs
```

### 3.3 重启 OpenClaw

```bash
openclaw gateway restart
```

## 常见问题 FAQ

### Q1: NotebookLM 免费吗？

**是的**，目前完全免费，无额度限制。但 Google 可能调整政策，建议适度使用。

### Q2: 生成的视频是什么格式？

MP4 格式视频，带 PPT 画面和声音讲解。

### Q3: 登录时浏览器没弹出来？

**可能原因：**
1. 没装 `[browser]` 版本的 notebooklm-py
2. Playwright 没装好
3. 系统缺图形界面（服务器环境）

**解决：**
```bash
# 重装带浏览器支持的版本
uv tool uninstall notebooklm-py
uv tool install "notebooklm-py[browser]"
playwright install chrome
```

服务器环境可先在本地登录，再同步登录信息到服务器。

### Q4: 生成的视频能商用吗？

NotebookLM 服务条款目前允许个人使用，**商用建议：**
- 仔细阅读 Google 最新条款
- 考虑其他商业化方案

### Q5: 视频生成要多久？

看材料长度：
- 简单文章（1000字）：10-30分钟
- 复杂文档（上万字）：15-45分钟

AI 会显示进度。

### Q6: 能自定义视频声音吗？

目前 NotebookLM 声音固定（男声或女声），**暂不支持自定义音色**。

需要特定音色可考虑：
- 其他 TTS 工具（如 ElevenLabs）
- OpenClaw 的 TTS 功能（第6课）自己配音

### Q7: Skill 安装后没生效？

**排查：**
1. 确认目录结构正确
2. 重启 OpenClaw
3. 检查日志：`openclaw logs`
4. 确认 notebooklm 命令可用：`which notebooklm`

### Q8: 能生成多长的视频？

NotebookLM 根据材料长度自动决定时长：
- 简单主题：3-5分钟
- 复杂主题：10-15分钟
- 超长材料：可能压缩到 15-20 分钟

### Q9: 生成的视频质量如何？

**优点：**
- 语音自然流畅，不像机器人
- 内容结构清晰，有逻辑
- 自动提炼重点

**局限：**
- 画面是简单 PPT
- 声音固定，不能自定义

## 进阶技巧

### 技巧1：优化源材料，提升视频质量

视频质量取决于源材料质量：

**好的源材料：**
- 结构清晰（有标题、段落分明）
- 内容丰富（有足够细节和例子）
- 逻辑连贯（有明确主线）

**不好的源材料：**
- 只有大纲，没内容
- 太多链接，没实质内容
- 过于零散，没主题

### 技巧2：多轮优化

第一轮不满意，让 AI 调整：

**你：** "视频讲得太浅，加些技术细节？"

**你：** "视频太长，压缩到5分钟内？"

### 技巧3：做「视频生成流水线」

完整工作流：

```
写博客文章 → AI 生成视频 → 下载音频 → 配封面图 → 发布到B站
```

配合 OpenClaw 其他能力，这流程可全自动化！

### 技巧4：结合其他 AI 工具

NotebookLM 出音频内容，其他工具出画面：

- **PPT 生成**：Gamma、Tome 等工具出配图
- **视频剪辑**：剪映、CapCut 自动剪辑
- **字幕生成**：Whisper 自动生成字幕

### 技巧5：快速测试不同主题

想测试主题是否适合做视频？

**你：** "用 NotebookLM 快速生成 'XXX' 的视频，看看效果"

5分钟后就知道内容丰富度如何。
