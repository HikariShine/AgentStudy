## 先搞懂：什么是 Channel？

Channel 翻译成「频道」，但我觉得叫它**「接入渠道」**更直观。

**简单说**：Channel 是 OpenClaw 和外界对话的桥梁。没有 Channel，OpenClaw 就是个自闭的终端程序；有了 Channel，它才能「听得到」（接收消息）和「说得出」（发送回复）。

**OpenClaw 支持的 Channel 类型：**

| Channel | 特点 | 适合谁 |
|---------|------|--------|
| **飞书** | 国内稳定，企业友好，配置中等 | 国内用户首选 |
| **微信** | 覆盖广，配置更简单 | 想接入个人微信 |
| **Telegram** | 国际通用，配置简单 | 有科学上网条件 |
| **Discord** | 社区氛围好 | 开发者/技术社区 |
| **Slack** | 企业协作，集成度高 | 外企/团队协作 |

**这节课选飞书**，因为国内访问稳定，不用科学上网，文档详细，遇到问题好排查。

## 第一步：创建飞书应用

飞书接入需要你创建一个「机器人应用」，这个机器人就是 OpenClaw 在飞书里的「身份」。

### 1.1 进入飞书开放平台

打开浏览器，访问：https://open.feishu.cn/app

用飞书账号登录后，点击右上角的 **「创建应用」**。

![飞书开放平台创建应用入口](/home/shine/projects/AgentStudy/docs/config/3/feishu-create-app.png)

### 1.2 填写应用信息

| 字段 | 填什么 | 示例 |
|------|--------|------|
| 应用名称 | 给你的AI起个名字 | `ShineClaw` |
| 应用描述 | 简单说明用途 | `个人AI助手` |
| 应用头像 | 选个好看的图标 | 随便选一个 |

点击 **「创建」**。

**心理辅导**：这里不用纠结名字，后面可以随时改。先让它跑起来最重要。

---

## 第二步：配置机器人能力

创建完应用后，你需要告诉飞书：「这个应用是个机器人，能接收和发送消息」。

### 2.1 添加机器人能力

在应用详情页左侧菜单，点击 **「能力管理」** → **「添加能力」**。

找到 **「机器人」**，点击 **「添加」**。

![添加机器人能力](/home/shine/projects/AgentStudy/docs/config/3/feishu-add-bot.png)

### 2.2 配置机器人信息

添加机器人后，需要配置一些基本信息：

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 机器人名称 | 跟应用名一致 | 用户看到的名字 |
| 描述 | 你的AI助手 | 简单介绍 |
| 可见范围 | 全员可见 | 先选这个，后面可以限制 |

**保存配置**。

---

## 第三步：获取关键凭证

这是整个配置中最重要的一步——你需要获取三个关键信息，让 OpenClaw 能「冒充」这个机器人跟飞书服务器对话。

### 3.1 获取 App ID 和 App Secret

在应用详情页左侧，点击 **「凭证与基础信息」**。

你会看到：

- **App ID**（应用 ID）：一串字母数字，类似 `cli_xxxxxxxxxx`
- **App Secret**（应用密钥）：点击「查看」按钮显示，是一串很长的字符

![凭证信息位置](/home/shine/projects/AgentStudy/docs/config/3/feishu-credentials.png)

**重要提醒**：
- App Secret 相当于密码，**不要泄露给任何人**
- 建议现在就把这两个值复制到一个临时文本文件里，等下要用

### 3.2 获取 Verification Token

在左侧菜单点击 **「事件订阅」**。

页面里有个 **「Verification Token」**，这也是一串字符，复制下来。

这个 Token 用于验证飞书发来的消息是真的（防止有人伪造消息）。

---

## 第四步：配置权限

飞书对机器人能做什么有严格的权限控制。你需要明确告诉飞书：「我的机器人要接收消息、发送消息」。

### 4.1 添加权限

在左侧菜单点击 **「权限管理」** → **「申请权限」**。

搜索并添加以下权限：

- `im:message:send`（发送消息）
- `im:message:readonly`（接收消息）
- `im:chat:readonly`（读取群聊信息）

![权限申请界面](/home/shine/projects/AgentStudy/docs/config/3/feishu-permissions.png)

**添加完权限后，记得点击「申请」**，等待飞书审核（通常是自动通过，秒过）。

---

## 第五步：配置 OpenClaw

现在飞书这边配置完了，轮到 OpenClaw 了。

### 5.1 使用 Onboarding 向导（推荐）

运行：

```bash
openclaw onboarding
```

选择 **「Channels」** → **「Feishu」**。

按提示输入：

| 字段 | 填什么 | 示例 |
|------|--------|------|
| App ID | 刚才复制的 App ID | `cli_xxxxxxxxxx` |
| App Secret | 刚才复制的 App Secret | `xxxxxxxxxxxx` |
| Verification Token | 刚才复制的 Token | `xxxxxxxxxxxx` |

**注意**：长连接模式下不需要填写 Webhook URL，OpenClaw 会自动建立连接。

### 5.2 手动配置（备用方案）

如果向导不能用，直接编辑 `~/.openclaw/openclaw.json`：

```json
{
  "channels": {
    "feishu": {
      "appId": "cli_xxxxxxxxxx",
      "appSecret": "你的AppSecret",
      "verificationToken": "你的Token",
      "encryptKey": ""
    }
  }
}
```

**注意**：长连接模式不需要 `webhook.url` 配置。

## 第六步：配置事件接收方式（关键步骤）

OpenClaw 的飞书 Channel 支持两种接收消息的方式：

| 方式 | 原理 | 适用场景 |
|------|------|----------|
| **长连接模式**（推荐） | OpenClaw 主动连接飞书服务器，实时拉取消息 | **无需公网IP**，配置简单，个人用户首选 |
| **Webhook 模式** | 飞书主动推送消息到你的服务器 | 需要公网IP或内网穿透，企业用户可选 |

**这节课用长连接模式**——不需要公网服务器，不需要配置防火墙，直接就能跑起来。

### 6.1 切换到长连接模式

回到飞书开放平台的 **「事件订阅」** 页面：

1. 找到 **「接收方式」** 设置
2. 选择 **「使用长连接接收事件」**
3. 保存配置

**心理辅导**：长连接模式下，OpenClaw 会主动连接飞书，所以你不需要暴露任何端口到公网，家里内网直接就能用。

### 6.2 配置订阅事件类型

在同一页面，找到 **「添加事件」**，添加以下事件：

- `im.message.receive_v1`（接收消息事件）

![事件订阅配置](/home/shine/projects/AgentStudy/docs/config/3/feishu-event-subscription.png)

## 第七步：发布应用并测试

### 7.1 发布应用版本

回到飞书开放平台，左侧菜单点击 **「版本管理与发布」** → **「创建版本」**。

填写版本信息：
- 版本号：`1.0.0`
- 更新说明：`初始版本`
- 可用范围：**「所有员工」**（或指定范围）

点击 **「保存并发布」**。

### 7.2 在飞书里找到你的机器人

打开飞书手机App或桌面端：

1. 在搜索框输入你的机器人名称
2. 找到机器人，点击进入
3. 点击 **「添加到通讯录」**

### 7.3 发送测试消息

在机器人的单聊窗口，发送：

```
你好
```

**如果一切正常**，你会看到 OpenClaw 回复你！

## 常见问题

**Q: 长连接模式和 Webhook 模式有什么区别？**

A: 长连接模式是 OpenClaw 主动连接飞书服务器拉取消息，**不需要公网IP**；Webhook 模式是飞书主动推送消息到你的服务器，需要公网IP或内网穿透。个人用户推荐长连接模式。

**Q: 配置后收不到消息怎么办？**

A: 检查以下几点：
1. OpenClaw 是否已启动？运行 `openclaw gateway status` 查看
2. 飞书事件订阅里是否切换到了「长连接接收事件」模式？
3. 是否订阅了 `im.message.receive_v1` 事件？
4. 是否已发布应用版本？未发布的应用只能开发者自己使用

**Q: 可以同时在多个群聊里使用吗？**

A: 可以。把机器人添加到群聊后，@机器人发送消息，它会在群里回复。

## 附录：微信接入（更简单！）

如果你更习惯用微信，OpenClaw 也支持接入个人微信，而且配置比飞书还简单。

**第一步**：在 OpenClaw 所在机器上执行：

```bash
npx -y @tencent-weixin/openclaw-weixin-cli@latest install
```

**第二步**：按终端提示，使用微信扫码登录。

**第三步**：完成！你的 OpenClaw 现在可以在微信里接收和回复消息了。
